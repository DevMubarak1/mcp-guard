# SUPPORT.md for mcp-guard

## Getting Help

- **Bug Reports:** Open an issue with the `bug` label. Include your Docker/OCI setup, MCP server details, and the policy that triggered.
- **Feature Requests:** Open an issue with the `enhancement` label describing the guard rule or MCP protocol feature you need.
- **Usage Questions:** Open an issue with the `question` label.
